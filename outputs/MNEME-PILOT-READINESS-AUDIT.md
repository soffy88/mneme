# Mneme Real-World Validation Readiness Audit

Audit scope: engineering readiness only. This audit does not claim real student,
randomized, production, commercial, retention, transfer, or causal learning
evidence.

## Baseline and implementation

- Baseline HEAD: `1f59f4d194e6e934a4b0f6348ab78dc09bd0867c`
- Working tree was based on `origin/main`; no production database or service was
  changed.
- Pilot-specific behavior is opt-in and fail-closed. `PILOT_MODE`,
  `PILOT_ENABLED`, protocol/cohort configuration, and rollout controls default
  off; the kill switch disables pilot behavior without disabling ordinary
  learning.
- The implementation reuses the existing LearningEvent, evaluation, cognitive,
  policy, privacy, purge, and export boundaries. It adds no second event,
  learner-model, or analytics system.

## Readiness capabilities

- `PilotEnrollment`, `PilotAssignment`, and `PilotMeasurementSchedule` are
  protocol-versioned, student-scoped, auditable, and represented in the purge
  inventory.
- Consent is a technical gate only. Protocols requiring consent accept only
  `GRANTED`; revocation invalidates future scheduled measurements. No consent is
  generated by the system.
- `EvidenceContaminationClassifier` is the single classifier for clean,
  AI-assisted, hint-assisted, answer-exposed, invalidated, and unknown evidence.
  Independent evaluation mode records assistance requests and invalidates the
  affected evidence without preventing normal help.
- Delayed measurements use protocol-configured windows and injectable time;
  duplicate scheduling is deterministic and late, early, duplicate, and
  contaminated attempts are represented explicitly.
- Retention, near/far transfer, independent-no-AI accuracy, JOL calibration, and
  RMG/AM calculators return null/insufficient status when evidence is missing.
  RMG/AM requires active learning time and excludes idle, background, upload,
  AI-latency, and system-wait time; session wall-clock is not used as a proxy.
- `PilotAnalysisReport` includes data quality, missingness, contamination,
  protocol/model/policy versions, cutoff, endpoint results, limitations, and a
  deterministic analysis manifest. Replay verifies the input checksum.
- Analysis mode is descriptive unless protocol assignment and observed data
  satisfy the randomized-assignment contract. `claim_guard` blocks causal
  language outside that contract. Evidence registry promotion requires a stored
  analysis artifact.
- Export contains pilot metadata only; raw answers and sensitive process fields
  are excluded. A minimal admin dashboard reports `NO REAL-WORLD EVIDENCE YET`
  when the registry has no evidence.
