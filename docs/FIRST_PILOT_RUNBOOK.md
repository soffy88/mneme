# First Pilot Runbook

No pilot result is implied by this checklist. The owner must complete each gate in order.

1. Owner approves the frozen protocol.
2. Resolve legal, minor-data, guardian-consent and research-ethics requirements.
3. Deploy through `docs/PRODUCTION_DEPLOYMENT.md`.
4. Verify all feature flags and early-access controls.
5. Freeze protocol/version and record the analysis/code SHA.
6. Create the approved cohort without unnecessary PII.
7. Record consent before enrollment where required.
8. Enroll only eligible users and record assignment audit metadata.
9. Collect baseline evidence.
10. Run the learning period through the normal LearningEvent → State → Policy path.
11. Collect immediate measurement.
12. Schedule and collect D7 measurement when its window opens.
13. Schedule and collect D30 measurement when its window opens.
14. Collect near-transfer and far-transfer evidence.
15. Collect independent-no-AI evidence under the contamination contract.
16. Pass the data-quality gate; do not fill missing data.
17. Freeze the analysis input and manifest.
18. Generate the descriptive/observational/randomized report only when its protocol conditions are met.
19. Register evidence only with the corresponding analysis artifact.
20. Perform owner/legal claim review. Never state that Mneme improves learning without valid randomized evidence.
