## 二、`kind` 字段：text 与 gloss

前端默认只展示 `text` 级，`gloss` 作为篇目下的字词/句子级附属条目不单独出地图入口。

| `kind` | 含义 | 判定 | 数量 |
| :--- | :--- | :--- | ---: |
| `text` | 篇目、诗作、人物、事件级 | `shici_jianshang`、`mingpian`、`mingzhu_yuedu`、`wenyan_yuedu`、`wenhua_changshi`、各类 `*_yuedu`、`xiezuo` 等 | **482** |
| `gloss` | 字词释义、名句/翻译、句式、字音字形、成语等依附篇目的条目 | `wenyan_word`、`wenyan_syntax`、`mingju`、`zixing_ziyin`、`chengyu`、`cizu_yunyong`、`biaodian`、`bingju` | **1269** |

字段位置：`ku_id, ku_name, grade, kind, url, year, place, person, label, confidence, reason`。
测试会反向读取 `ku_packages` 的 `ku_type`，断言 `kind` 与 `ku_type` 的映射完全一致，
防止后续数据漂移。

## 三、生成与校验

### 3.1 URL 结构

```json
{
  "ku_id": "TONGBIAN-G11-CHINESE-SBXM-ku-楼船夜雪瓜洲渡-铁马秋风大散关",
  "ku_name": "楼船夜雪瓜洲渡，铁马秋风大散关",
  "grade": "G11",
  "kind": "text",
  "url": "https://deanchen.me/jiangshan-map/?year=1172&place=%E7%93%9C%E6%B4%B2%E6%B8%A1,%E5%A4%A7%E6%95%A3%E5%85%B3",
  "year": 1172,
  "place": "瓜洲渡,大散关",
  "person": null,
  "label": "第三方示意地图，非教材标准地图",
  "confidence": "high",
  "reason": "陆游《书愤》追忆南郑前线军旅（1172），同联并写瓜洲渡与大散关"
}
```

- 地点链：`?year=<整数>&place=<中文>`；多站路线逗号分隔、逐站百分号编码；
- 人物链：`?person=<key>`，`year` 为 `null`（仅 85 条，18 位人物）；
- BCE 用负整数（如《谏逐客书》`-237`、《鸿门宴》`-206`、《陈涉世家》`-209`）；
- 不使用 `hover/zoom/lang` 等额外参数，参数集合固定为 `year/place/person`。

### 3.2 解析校验（用本地 atlas 只读数据）

校验器按站点 `resolvePlace()` 的“名关 → 地名志 → 地名行 → 事件点 → 行迹站”顺序，
对每个 place token 检查 name/alias/modern，并做“去省/市/州/关/郡/府/路/城”后缀回退；
人物用 `PERSON_PROFILES` 的 `key/zh/aliases/tokens` 校验。

- **1751 / 1751 全部可解析，0 条因解析失败被剔除**；
- 人物 key 只使用 `PERSON_PROFILES` 中真实存在的 18 位（屈原、刘禹锡、李白、诸葛亮、
  苏轼、玄奘、杜甫、陆游、欧阳修、王维、白居易、陶渊明、范仲淹、辛弃疾、文天祥、
  曹操、柳宗元、韩愈）；
- 多站路线逐 token 校验，如 `嘉州,三峡,重庆`（《峨眉山月歌》出蜀路线）、
  `瓜洲渡,大散关`（《书愤》）、`长安,成都`（《送杜少府之任蜀州》）；
- 年份全部落在 `-403..2026`；系年早于前 403 的（《论语》《老子》《曹刿论战》长勺之战）
  按 §四剔除，不做“截断到前 403”的假挂链。

1. **“能解析”不等于“该挂”**：如“当涂”是词义而非地名、“北海”解析到广西北海

2. **不把虚构/小说地点当真**：桃花源、梁山泊保留但标 `medium` 并在 `reason` 写明
   “文学虚构/小说托言”；大观园、鲁镇这类没有真实锚点的直接剔除。

## 九、边界与合规

1. **只做外链**：未复制对方 JS/几何/事件/坐标，未改 `ku_packages`；GPL 传染风险按
   评估报告保持最低。生成脚本未入库，避免把第三方地名/别名表以代码形式固化。
2. **必须显示标识**：所有入口展示“第三方示意地图，非教材标准地图”，不用于判分、
   不做边界题材料；`medium` 条目只作情境入口。
3. **同名异地继续拆分**：赤壁（208 蒲圻 / 1082 黄州）、潼关（1329 张养浩 / 1882
   谭嗣同）、诸葛亮（人物档案 / 227 汉中 / 234 五丈原 / 207 隆中）。
4. **小说与史实分离**：《西游记》只保留 3 条“作者与时代背景”走玄奘人物档案，
   其余 46 条情节/字词条剔除；《水浒传》/《智取生辰纲》保留但标文学地点。
5. **不做“凑数”挂链**：跨篇目虚词、通用应试方法、成语释义、寓言虚指地点等
   共 311 条剔除并留痕，宁缺毋滥。
6. **合规前置**：面向学生全量上线前，仍需法务确认许可证与地图展示责任；本批
   不构成合规签字。

## 附录：字段与复现

`links.json` 每条字段（顺序固定）：

```text
ku_id, ku_name, grade, kind, url, year, place, person, label, confidence, reason
```
